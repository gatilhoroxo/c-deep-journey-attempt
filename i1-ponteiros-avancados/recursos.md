## 🛠️ Ferramentas e Compiladores

### Compiladores

1. **GCC (GNU Compiler Collection)**
   - 🔗 [https://gcc.gnu.org](https://gcc.gnu.org)
   - ✅ Padrão em Linux
   - ✅ Otimizações excelentes
   ```bash
   # Compilação básica
   gcc -Wall -Wextra -g programa.c -o programa
   
   # Com otimização
   gcc -O2 -Wall programa.c -o programa
   
   # Debug completo
   gcc -g -O0 -Wall -Wextra programa.c -o programa
   ```

2. **Clang (LLVM)**
   - 🔗 [https://clang.llvm.org](https://clang.llvm.org)
   - ✅ Mensagens de erro melhores
   - ✅ Análise estática integrada
   ```bash
   clang -Wall -Wextra -g programa.c -o programa
   ```

3. **MSVC (Microsoft Visual C++)**
   - 🔗 Visual Studio
   - ✅ Windows
   - ✅ IDE integrada

### Debuggers

4. **GDB (GNU Debugger)**
   - 🔗 [https://www.gnu.org/software/gdb/](https://www.gnu.org/software/gdb/)
   - ✅ Debugger mais poderoso
   ```bash
   # Comandos úteis
   gdb ./programa
   (gdb) break main
   (gdb) run
   (gdb) print *ponteiro
   (gdb) x/10x ponteiro  # Examinar memória
   ```

5. **LLDB**
   - 🔗 [https://lldb.llvm.org](https://lldb.llvm.org)
   - ✅ Alternativa ao GDB
   - ✅ Interface mais amigável

### Análise de Memória

6. **Valgrind**
   - 🔗 [https://valgrind.org](https://valgrind.org)
   - ✅ Detecta memory leaks
   - ✅ Invalid reads/writes
   - ✅ Use of uninitialized values
   ```bash
   valgrind --leak-check=full --show-leak-kinds=all ./programa
   ```

7. **AddressSanitizer (ASan)**
   - 🔗 Integrado em GCC/Clang
   - ✅ Mais rápido que Valgrind
   - ✅ Detecta buffer overflows
   ```bash
   gcc -fsanitize=address -g programa.c -o programa
   ./programa
   ```

8. **Dr. Memory**
   - 🔗 [https://drmemory.org](https://drmemory.org)
   - ✅ Windows, Linux, Mac
   - ✅ Similar ao Valgrind

### Análise Estática

9. **Cppcheck**
   - 🔗 [https://cppcheck.sourceforge.io](https://cppcheck.sourceforge.io)
   - ✅ Encontra bugs sem executar
   - ✅ Análise de ponteiros
   ```bash
   cppcheck --enable=all programa.c
   ```

10. **Clang Static Analyzer**
    - 🔗 [https://clang-analyzer.llvm.org](https://clang-analyzer.llvm.org)
    - ✅ Análise profunda
    - ✅ Integrado no Clang
